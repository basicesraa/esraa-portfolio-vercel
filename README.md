# Esraa's Portfolio Website

A personal portfolio website built with **Next.js** and **Tailwind CSS**.

All text content lives in JSON files inside `src/content/`, so you can edit the portfolio without touching component or CSS files.

---

## 1. What This Is

A static Next.js portfolio website that showcases:

- Projects
- Background and experience
- Technical capabilities
- Tools and technologies
- Contact information

The design, layout, and color system are already configured.

You mainly need to update the content files with your own information.

---
